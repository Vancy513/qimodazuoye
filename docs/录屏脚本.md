# 演示录屏脚本（建议 2~3 分钟，一次录完）

> 用系统自带录屏（Win + G）或手机录屏，**不要剪辑拼接**，老师要看真实操作。

## 录制前

1. 清除应用数据：控制台 → 场景页 → 「恢复默认演示数据」。
2. 确认规则库是 5 条规则，日志为空。
3. 开始录制，先展示手机桌面点击应用图标启动。

## 分镜

| 时间 | 操作 | 解说要点 |
| --- | --- | --- |
| 0:00-0:20 | 启动应用，停在控制台 | 「默认环境 29℃、湿度 38%、光照 25%、有人，顶部显示命中 3 条」 |
| 0:20-0:40 | 拖动温度到 22℃，看命中数变化 | 「拖动会实时预览命中情况，但设备不会自己动，要按运行」 |
| 0:40-1:00 | 点「运行联动」，观察三张设备卡片变化 | 「空调 24℃、灯 70%、加湿器 60%，底部列出变化」 |
| 1:00-1:30 | 进入规则库，打开「昏暗开灯」查看双条件 | 「光照<30 且有人，两个条件都满足才触发」 |
| 1:30-1:50 | 进入日志页，展开刚才那条记录 | 「环境快照、执行顺序带序号、冲突处理」 |
| 1:50-2:20 | 场景页选「深夜休息」，观察冲突记录 | 「无人熄灯 P5 压制昏暗开灯 P4，日志里写明谁跳过」 |
| 2:20-2:50 | 返回桌面，后台杀掉应用，重新打开 | 「规则、设备状态、日志都恢复了」 |
| 2:50-3:00 | 规则库新建一条规则并保存 | 「可以扩展，保存前会校验」 |

## 录完检查

- [ ] 画面里能看到手机状态栏/模拟器窗口，证明是真实运行
- [ ] 杀进程那一段能看清是从后台划掉再重开
- [ ] 视频不超过 5 分钟，文件小于 100MB（超出可压缩或传网盘）
